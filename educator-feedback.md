1. Educator Dashboard – Student Verification Studio workflow
   I am seeing services inside the Student Verification Studio with a status of Awaiting Client. This service is too early in the workflow to appear in the educator verification queue.

The intended workflow is:

Service Started → Service Completed → Evidence Submitted → Awaiting Client Confirmation → Client Confirms → Ready for Educator Verification → Educator Verifies/Returns

A service that is still Awaiting Client Confirmation should remain outside the educator verification queue.

The Student Verification Studio should display a service only when it reaches Ready for Educator Verification.

If educators need visibility of earlier records for monitoring purposes, those can appear separately under something like Student Activity or Pending Client Confirmation, rather than inside the verification queue.

Within the Verification Studio, the educator should immediately see:
Student | Service | Date Completed | Client Confirmed | Evidence | Logged Time | Verification Status | Review

This way, when an educator opens the Verification Studio, everything there requires an actual educator decision.
