1. Employer Portfolio View – Make Work the Primary Focus

When an employer clicks a student from Browse, I want the page to open as the student’s visual portfolio first.

The current page leads with the Skill Summary and pushes the actual work further down. Please reverse that hierarchy.

Preferred layout:

Top header

Student name
Institution
Verified Services
Verified Hours
Categories
Shortlist
Copy/Share Portfolio Link
Immediately below the header: VERIFIED PORTFOLIO

Show the student’s verified work as the main visual gallery. Photos should be large and prominent, grouped by service where appropriate:

Cornrows — Braiding · Verified
[photos]

Round-brush Blow-dry — Blow-dry · Verified
[photos]

Root Touch-up — Colour · Verified
[photos]

Employers should be able to click a portfolio item to see the full service record, additional images and verified details.

Move Skill Summary out of the main portfolio feed.

It could become either:

a Skills button/tab beside Portfolio, or
a section in the side navigation called Skills & Verification.
Suggested student portfolio navigation:

Portfolio | Skills & Verification | Experience/Profile

The Portfolio should be the default view.

Skill Summary can then show the structured evidence behind what the employer has already seen visually: service categories, number completed, verified hours and specific verified techniques.

The employer journey should essentially be:

Browse Students → Open Student → See Work Immediately → Explore Work → Check Verified Skills/Hours → Shortlist

I’d also change that large green message — “Every service shown here was verified by an educator…” — into a smaller Verified Portfolio badge/statement near the student name. It is valuable, but right now it takes up prime visual space.

For Kosmè, the distinction can be very strong: the pictures attract the employer; the verification data gives the pictures credibility. That should drive this screen.

2. Remove Educators Metric
   Please remove Educators from the student portfolio summary. The number of educators involved in verification has limited relevance to an employer viewing the candidate.

Keep the employer-facing summary focused on: Verified Services | Verified Hours | Skill Categories

Verification by an educator can still be communicated through the Verified badge on each service and the overall statement that portfolio work has been educator-verified.

I would also prefer three wider summary cards rather than adding a fourth metric simply to fill the space
